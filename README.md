# javascript-calculator-precourse

## 기능 요구 사항

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

- 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
  - 입력: 문자열
  - 기본 구분자: 쉼표(,) or 콜론(:)
- 커스텀 구분자를 지정할 수 있다.

  - 커스텀 구분자: "//"와 "\n" 사이에 위치하는 문자
  - 문자열 앞부분에 작성
  - ex)

    ```
    문제
    - 입력값: `"//;\n1;2;3"`
    - 커스텀 구분자: 세미콜론(;)

    풀이 과정
    - `//;\n`: 커스텀 구분자는 ; 이다.
    - `1;2;3`: 1+2+3
    - 결과값: 6
    ```

- 사용자가 잘못된 값을 입력할 경우
  - Error 발생
  - "[ERROR]"로 시작하는 메시지 출력
  - 애플리케이션 강제 종료
- 올바른 입력: 구분자와 양수로 구성된 문자열

## 입출력 형식

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 요구사항 분석 🧙‍♂️

- 입력 에러케이스
  - 음수 입력
  - 커스텀 구분자가 없는 경우: (,), (:) 외의 구분자를 사용한 경우
  - 커스텀 구분자가 있는 경우: 커스텀구분자, (,), (:) 외 기타 구분자를 사용한 경우
    - 💬 구분자에 대한 예외처리는, 통과하는 케이스를 만들고 에러 캐치는 try, catch로 잡아보자(하나하나 에러 처리를 만드는것보다 메서드 실행 과정에서 발생하는 에러를 포착하는 방식이 간편할 것 같다.)
- 커스텀 구분자 입력 에러케이스
  - 구분자가 1자 이상의 문자열인가
  - 숫자인가
- 기본 기능
  - 커스텀 구분자 설정이 있는가
  - 없다: (.) 또는 (:) 구분자로 문자열을 분리하여 숫자 추출 및 계산
  - 있다: 커스텀 구분자로 문자열을 분리하여 숫자 추출 및 계산
- 에러 케이스에는 에러를 발생시키고, 애플리케이션을 강제 종료한다.

## 구현할 기능 목록 🧙‍♂️

💬 요구사항을 정리하고 바로 코드를 작성해왔는데,(미리 설계하는게 더 막막하고 어렵게 느껴졌다. 그동안은 즉흥적으로 직관으로 작성했다.) 이렇게 구현할 기능의 우선순위를 먼저 작성해두는건 처음이다! 지금은 낯설지만 이렇게 진행할 경우의 이점을 경험해보자.

### 계산기

1. 문자열을 입력 받고 결과값을 출력하는 계산기 **(함수 calculator)**

### 계산 과정

1. 커스텀 구분자 설정 여부를 확인한다.**(함수 checkSeparator)**
   - 첫 숫자 등장 전까지의 문자열이 3글자인지,
   - "//+구분자+\n" 형식인지,
   - 구분자가 숫자가 아닌 문자가 맞는지
   - 반환 값: 구분자 문자열
2. 구분자로 문자열의 숫자를 추출하여 배열에 넣는다.**(함수 getOperand)**
   - 구분자: (,)&(:) or 커스텀 구분자(checkSeparator의 반환 값)
   - ❗️ "1,2:3" => 6 처럼 (,),(:)혼용 사용을 허용해야 함
     - 💬 split 메서드에 두가지 문자열을 옵션으로 줄 수 있는지.. 알아봐야 함.
   - ❗️ 공백 비허용
3. 배열을 순회하며 계산후 결과값을 반환한다. **(함수 addOperands)**

## 프리코스 과제 주의사항

- Node.js 22.19.0 버전에서 실행 가능해야 함
- 프로그램 실행의 시작점은 App.js의 run()
- package.json 변경 금지. 기타 외부 라이브러리 사용 금지.
- 프로그램 종료 시 process.exit()를 호출하지 않는다.
- 네이밍 컨벤션 주의
  - 변수명, 클래스명 등: 영어 사용. 특수문자 사용 금지
  - 상수명: SNAKE_CASE
- 사용자의 값 입출력에는 우테코가 제공하는 Console API를 사용한다.
  - 입력: Console.readLineAsync()
  - 출력: Console.print()
